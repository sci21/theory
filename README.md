# EDU RECALL v4.1 — 8단원 인터랙티브 마인드맵

v4의 312문항 퀴즈와 8개 단원 개념도를 유지하면서 가지 접기·펼치기 클릭 충돌을 수정하고 세부 가지를 추가했습니다. 편집 기능은 없습니다.

## 설치
전체 파일을 GitHub Pages 저장소의 최상위 디렉터리에 업로드하고 기존 파일을 덮어씁니다. Settings → Pages에서 main / (root)를 선택합니다. 브라우저에서 Ctrl+Shift+R 새로고침하세요.

## 사용법
concept-map.html에서 단원을 선택하면 해당 단원의 마인드맵이 나타납니다. 노드를 누르면 설명과 PDF 페이지를 표시합니다. **노드 오른쪽의 작은 + / − 버튼**으로 해당 가지를 접고 펼칩니다. 노드를 더블클릭해도 접고 펼칠 수 있습니다. 오른쪽 아래의 커다란 + / −는 확대/축소용입니다. 휠로 확대, 드래그로 이동할 수 있습니다. 검색은 현재 단원에서 작동합니다.

## 수록 범위
교육과정: p.2–7 (기존 시범 지도 유지, 세부 가지 보강; 나머지 미수록)
교육심리: p.20–47 / 교수방법·교육공학: p.48–76 / 교육평가: p.77–95 / 교육사회: p.96–108 / 교육행정: p.109–134 / 생활지도: p.135–147 / 교육철학: p.148–155

이 개념도는 서브노트의 주요 개념 중심 요약이며 세부 표·수식·모든 개념을 전수 수록한 자료가 아닙니다. 내용 확인 시 PDF 원문을 참조하세요.

## v4.1 수정 사항
- 개념 노드 클릭과 캔버스 드래그 이벤트 분리 (접기/펼치기 클릭 오류 완화)
- 8개 단원에 세부 학습 가지 추가 (원래 개념도의 간략한 설명을 세부 항목으로 구조화)
- 312문항과 학습 기록 기능 보존
- 브라우저 런타임 검증은 실행 환경 접근 제한으로 미완료. JS 구문 검사 수행.
